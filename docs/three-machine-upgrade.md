# 三机器升级保护与原地播报（1.1.0-test.3）

本版保留用户配置和业务数据，隔离并重建临时运行状态。新测试包经 Windows 构建与验收后，以独立标签和草稿交付；既有草稿、标签与安装包保持不变。

## 数据规则

| 内容 | 处理 |
| --- | --- |
| 密钥、模型、音色、机器人地址、管理密码及保存的配置 | 机器 1 沿用原用户数据目录；已有文件不被安装默认值覆盖 |
| 点位、巡游顺序、话术、知识库、音频及关联 | 机器 1 保留原路径和内容 |
| 机器 2、3 | 在各自目录初始化空白业务数据；已有数据继续保留，不复制机器 1 的密钥或内容 |
| 用户保存的 `data/tts-cache` 音频库 | 属于业务数据，保留 |
| PCM、占用记录 | 每台机器每次启动使用带随机标识的独立运行目录；不继承旧占用 |
| 播放队列、巡游进度、原地播报循环 | 不恢复自动播放；用户重新启动任务 |

旧版根目录缓存、损坏占用记录、未知文件和活跃进程目录不清理。仅回收所有权信息匹配、进程已确认退出且不是符号链接/目录联接的运行目录；进程编号复用或无法确认退出时保留，不阻塞新播放。

新旧版本应由同一个 Windows 用户运行，旧数据必须完整可读。升级前停止现场任务、退出程序，备份 `%APPDATA%\robot-live-ui\`。**无需卸载所有旧版本，也无需手动清空缓存或用户数据。** 已经删除的数据只能从备份恢复。

## 进程交接

- 安装器检查旧主程序、Electron 后台及已识别安装目录下的媒体程序。确认退出后才替换文件；查询、终止失败或超过 10 秒都中止并提示重试，不删除用户数据。
- 同一机器的连续重启请求共用一次操作，确认旧后台退出后才启动替代后台；启动时读取最新已保存设置。
- 停止失败或 10 秒未退出会返回错误并解除等待，不同时启动第二个后台。关闭工作区会取消待执行重启。
- 机器 2 保存设置只影响机器 2；切页、隐藏和分屏不销毁其他后台。完整打开才显示欢迎页，单机后台重启不重放欢迎页。

## 原地播报

在“播报控制”输入文字，使用“系统设置 → 巡游讲解”的配置。直接朗读原文，不改写、不移动机器人。手动播报仍用“过渡音频与手动播报”组。

默认一次，循环开启后整段播完再重复。停止会取消当前准备/播放及下一轮；错误会结束循环，不持续重试。重复播放不会向已保存 TTS 音频库追加重复条目。

巡游（包括暂停）、手动播报、原地播报互斥，前端禁用与后端校验同时生效。沿用已有音频输出、助播暂停、人工暂停与弹幕优先级；机器人断开或更换时停止机器人端的原地播报，切换输出目的地也停止，单独调整音量不停止。

状态由后台维护。切页、收起机器栏、分屏、界面重连均继续原来的任务；界面只重新查询状态，不自动重发播放命令。后台重启或应用重开后处于待机。循环选项不是持久化的自动播放任务。

## 自动验收

```bash
npm run test:all
npm --prefix robot-ui run build
npm --prefix robot-ui run test:upgrade-audio
```

- 数据测试使用合成旧配置，覆盖密钥、点位、管理密码、话术、素材和 TTS 音频库；机器 2/3 首次为空、已有数据不覆盖。
- 缓存测试覆盖存活/被复用 PID、损坏记录、强制退出恢复、并行目录、未知所有者、符号链接/目录联接。
- 重启测试覆盖重复请求、终止返回失败/抛错/无退出通知、超时、关闭期间取消，以及其余两台不受影响。
- Electron 升级音频测试连接三个模拟机器人，将实际发送的 PCM 与独立 FFmpeg 解码逐字节比较；验证切页/分屏、连续保存合并重启、崩溃恢复和重开不自动播放。本地结果保存在 `output/machine-upgrade-smoke/machine-upgrade-smoke.json`，Windows 打包验证结果保存在 `release/machine-upgrade-smoke/`。
- 原地播报测试覆盖凭据归属、整段循环、取消准备/播放/轮间等待、互斥、异常结束、状态重连和三实例隔离。
- `robot-ui/test/installer-exit-guard.test.mjs` 在 Windows 自动运行真实 PowerShell 进程测试；在 macOS 明确跳过该项。

## Windows 与现场确认

交付工作流要求 Windows 回归、安装器编译、打包运行时、三 OCR 并行、真实打包程序的音频与数据升级检查通过；安装器进程测试覆盖终止失败、权限/查询失败和超时中止。验收报告按对应提交和运行记录判断，不以本地通过替代 Windows 结果。

模拟端点只能验证发送内容，不能确认实际机器人扬声器的听感与接收缓冲。拿到测试包后，仍需现场分别验证手动播报、原地播报循环及 MP3；先退出程序并备份用户数据，保留旧安装包用于回退。没有现场证据时，不宣称实际机器人验收通过。
